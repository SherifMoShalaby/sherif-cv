AI Staffing Platform

Entelligence · Tech Lead & Architecture Owner

May 2026 - present

Problem

An AI staffing product needed a retrieval-augmented assistant that answers from the organisation’s own corpus rather than from the model’s priors. It also had to be verifiable, because a plausible-sounding wrong answer is worse than no answer in a hiring context.

Impact

  • A one-button end-to-end harness that boots a throwaway database and both applications for roughly 50 Playwright tests. The project had no end-to-end verification before it.
  • A model-evaluation suite scoring RAG answers for relevance and factuality, so answer quality is measured rather than assumed.
  • A ~20-ticket technical-debt programme delivered across both stacks.

Architecture

Retrieval-augmented chat on Java 25 and Spring AI over PostgreSQL/pgvector, streaming answers through a tool-calling loop, with an Angular front end on AWS ECS provisioned via Terraform. Third-party sync was moved out of the request transaction into a transactional outbox; session revocation and signed invitation and reset tokens were added.

  • Java 25
  • Spring AI

  • Tool calling
  • Streaming
  • Angular 21
  • AWS ECS
  • Terraform
  • Playwright

My role

Own the architecture end to end. Set the engineering standards the team writes and reviews code against, including the AI-assisted review and planning workflow now shared across the repository. Own backlog planning, architecture overviews and code review.
